# Tab Dedup

ページを開いたとき、同じページ（origin + path が一致）が既に別のタブで開かれていれば、

- 既存のタブへ移動（このタブは閉じる）
- 古いタブを閉じる（このタブを使う）
- 何もしない（× で閉じる）

を選べる小さな通知をページ右上に表示する Chrome 拡張機能です。通知は操作しなければ 8 秒で自動的に閉じます（マウスを乗せている間・フォーカス中は止まります）。WXT + Svelte + Vite+ で構成しています。

## サイトごとの設定

origin（スキーム + ホスト + ポート）ごとに次を設定できます。ルールのないサイトにはデフォルト設定が使われます。

- 重複したときの動作: 通知を表示して選ぶ / 何もしない / 自動で既存のタブへ移動 / 自動で古いタブを閉じる
  - 自動で移動・クローズしたときは「元に戻す」付きの通知が出ます
- 重複を探す範囲: すべてのウィンドウ / 同じウィンドウのみ
- ピン留めタブを重複として扱うか
- クエリ（`?` 以降）まで一致したときだけ重複として扱うか（パラメータの順序は問わない。初期値はクエリを無視）

設定はオプションページ（全ルールの一覧とデフォルト設定）と、ツールバーアイコンのポップアップ（開いているサイトのルール）から変更できます。

## 開発

```bash
vp install
pnpm run dev      # Chrome が起動し拡張が読み込まれる
pnpm run build    # .output/chrome-mv3 に出力
vp test          # Vitest (Vite+ built-in)
vp check         # fmt + lint + type check
pnpm run check:svelte
```
